# 🌦️ WeatherApp

A modern, **responsive weather tracking app** built with **JavaScript** and designed using the **MVC pattern** for clean architecture. It fetches weather and time data from an **external API**, providing smart stats and dynamically adjusting its background based on local time.

## 📌 Features
- **Smart Weather Insights** – Displays real-time weather and time data.
- **Dynamic Backgrounds** – Colors shift based on local time (e.g., night = black).
- **MVC Architecture** – Clear separation between **Model, View, and Controller** for maintainability.
- **Fully Responsive** – Works smoothly across devices.
- **Best Practices** – Designed with clean code and scalability in mind.
